# 🤖 AI Pro Hub — One-Person Resume Templates

A collection of AI-powered, modern resume & portfolio templates designed for solo professionals, developers, and AI enthusiasts.

## ✨ Templates Included

| Template | Style | Best For |
|----------|-------|----------|
| `index.html` | Modern AI Dark | Tech professionals, AI engineers |
| `templates/minimal.html` | Clean Minimal | Designers, writers, consultants |
| `templates/creative.html` | Bold Creative | Artists, creators, innovators |

## 🚀 Quick Start

1. **Fork or clone** this repo
2. **Edit the HTML file** of your chosen template — replace placeholder content with yours
3. **Deploy to GitHub Pages** (free!) or any static host
4. **Customize colors, fonts, and sections** to match your brand

## 🎨 Customization

Each template includes:
- **AI-themed visual design** with gradient accents
- **Responsive layout** — looks great on mobile & desktop
- **Dark/Light mode toggle**
- **Animated skill bars**
- **Project showcase cards**
- **Contact form with Formspree integration**
- **AI chatbot assistant placeholder** (ready for OpenAI/Claude integration)
- **Typing effect hero section**
- **Smooth scroll animations**

## 🛠️ Tech Stack

- Pure HTML5 + CSS3 + Vanilla JavaScript
- No frameworks required — just open the HTML file
- Optional: Add React/Vue/Next.js later

## 📦 Deploy to GitHub Pages

```bash
# 1. Push to GitHub
git add .
git commit -m "Initial resume template"
git push origin main

# 2. Go to repo Settings > Pages
# 3. Select "Deploy from branch" > main
# 4. Your site is live at https://yourusername.github.io/jishua/
```
